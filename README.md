# Тренажёры английского · @dzerazavr

Интерактивные HTML-тренажёры для учеников. Результаты попадают в одну общую Google Таблицу, а учитель смотрит их на дашборде.

## Как это устроено

```
index.html                         каталог тренажёров
lessons/<страница>/index.html      тренажёр: только данные упражнений
theory/, theory/pdf/               сюда лягут страницы и PDF с теорией
dashboard/index.html               дашборд учителя
dev/styleguide.html                служебная: элементы дизайна и тестовая отправка
assets/css/theme.css               общий дизайн «Whimsical Retro» (палитра и шрифты)
assets/js/config.js                адрес Apps Script, ключ учеников, ссылка на таблицу
assets/js/tracker.js               кто ученик + отправка ответов (с очередью без интернета)
assets/js/exercises.js             движки упражнений, итог, «Пройти ошибки ещё раз»
apps-script/Code.gs                копия кода из Google Apps Script
```

Ученик определяется по ссылке: `?s=almina&n=Альмина`. `s` — это `student_id` (латиница, без пробелов), `n` — имя для приветствия. Если в ссылке нет `?s=`, страница спросит имя и запомнит его на этом компьютере.

Ответы уходят в таблицу после каждого «Проверить», итог — после «Показать итог». Если нет интернета, всё копится на компьютере ученика и досылается позже.

## Как добавить ученика

1. Откройте Google Таблицу → лист **Students** → новая строка:
   `student_id` (латиницей, например `kira`) · имя · уровень · учебник · флажок «активен» · заметки.
2. Откройте дашборд и нажмите **Обновить**: появится вкладка ученика.
3. На вкладке ученика есть готовая ссылка и кнопка «Скопировать». Это ссылка на каталог.
   Чтобы дать ссылку сразу на тренажёр, допишите её так:
   `…/lessons/<папка-тренажёра>/?s=kira&n=Кира`

Ученик больше не занимается? Снимите флажок «активен»: вкладка пропадёт, а результаты сохранятся.

## Как добавить новую страницу-тренажёр

1. Скопируйте папку `lessons/spotlight7-u01-errors` и назовите копию по-новому, например `lessons/spotlight6-u02-errors`.
2. В `index.html` новой папки поменяйте блок `PAGE`:
   - `id` — то же, что имя папки;
   - `title`, `kicker`, `subtitle` — заголовки;
   - `exercises` — список упражнений (форма описана в начале `assets/js/exercises.js`).
     Типы: `match` (пары), `gapBank` (слова из банка), `choice` (выбор), `typeFix` (исправить предложение),
     `order` (собрать предложение), `typeWord` (одно слово), `sort` (разложить по колонкам), `writing` (свободный текст).
3. Добавьте строку на лист **Pages**: `page_id` · название · тип (errors/theory) · темы · ссылка.
4. Добавьте карточку в главный `index.html` (скопируйте существующую `<a class="tile">`).
5. Опубликуйте изменения (см. ниже).

Проще всего попросить Claude: «сделай новый тренажёр для Киры по уроку 2, вот ошибки…». Он сделает шаги 1–5 сам.

## Где смотреть результаты

- **Дашборд** (`/dashboard/`). Вкладки: «Все ученики» и по одной на ученика. Внутри: последняя активность, сводка «По тренажёрам» (нажмите на строку, чтобы смотреть один тренажёр), прохождения, ошибки по темам, частые ошибки, письменные работы. При первом входе спросит **ключ учителя** (`teacher-…`).
- **Google Таблица**: `Answers` — каждый ответ, `Sessions` — каждое прохождение, `Summary` — сводка по ученикам.

Ключ учителя хранится в Apps Script: ⚙ Настройки проекта → Свойства скрипта → `TEACHER_KEY`.

## Google Apps Script: как менять код

Код лежит в таблице: Расширения → Apps Script (копия — `apps-script/Code.gs`).

После любого изменения кода:
**Развернуть → Управление развертываниями → карандаш ✎ → Версия: «Новая версия» → Развернуть.**
Так адрес веб-приложения не меняется, и `config.js` трогать не нужно.
(«Новое развертывание» создаёт новый адрес — тогда его придётся заново вписать в `config.js`.)

Первая настройка (уже сделана): создать таблицу → Расширения → Apps Script → вставить `Code.gs` → выполнить `setup` → Развернуть → Новое развертывание → Веб-приложение (запуск от моего имени, доступ: все) → URL в `config.js`.

## Про безопасность — честно

- Ключ учеников (`studentKey` в `config.js`) виден любому, кто откроет код страницы. Он защищает только от случайных запросов, а не от того, кто захочет специально записать мусор в таблицу.
- Поэтому в таблицу пишутся только имя ученика и ответы — никаких телефонов, почт и других контактов.
- Ключ учителя на сайте не хранится: дашборд спрашивает его и запоминает только в вашем браузере. Без него данные из таблицы не отдаются.
- Если ключ учителя попал не туда — поменяйте `TEACHER_KEY` в Свойствах скрипта.

## Как опубликовать изменения

Сайт работает на GitHub Pages из ветки `main`. После правок:

```
git add -A
git commit -m "Описание правки"
git push
```

Через 1–2 минуты изменения появятся на сайте.
